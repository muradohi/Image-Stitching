Computer Vision Utilities — Keypoints, Descriptors & Stitching

Summary

This repository / notebook contains a collection of computer-vision utilities focused on classical keypoint detection, descriptor computation, matching, and simple image stitching. The code implements and demonstrates:

  Harris corner detection and filtering of keypoints
  
  SIFT descriptor computation (if OpenCV SIFT is available) and a patch-based descriptor alternative
  
  Descriptor matching (euclidean or correlation) and correspondence filtering
  
  Homography estimation and image stitching
  
  Visualization helpers for keypoints, matches, and stitched results


Main functions 
The notebook defines the following high-level functions (useful names — open the notebook to see full docstrings and parameters):

  find_Harris_Key_Points — detect Harris corners and return keypoints
  
  compute_SIFT_descriptors — compute SIFT descriptors for keypoints (uses OpenCV SIFT if available)
  
  get_keypoints — alternative keypoint detector (non-SIFT path)
  
  get_descriptors_patch — compute patch-based descriptors around keypoints
  
  visualizeCorrespondence — show matched keypoints between two images
  
  stitchImages — estimate homography and stitch two images
  
  plot_results — helper to plot intermediate results and diagnostics


How to run
— Run interactively (recommended)

Open the notebook in Jupyter / JupyterLab and run cells in order. The notebook contains demonstration cells that load example images, detect keypoints, compute descriptors, match correspondences and produce stitched output.


Recommended usage patterns

  Use compute_SIFT_descriptors when you have opencv-contrib-python installed; otherwise fall back to get_descriptors_patch.
  
  Filter keypoints by response and apply non-maximal suppression to get robust correspondences (not all detectors are created equal across modalities).
  
  Use RANSAC when estimating homographies to make the stitching robust to outliers.



Outputs

  Typical outputs generated by the notebook:
  
  keypoints_visualization.png — input images annotated with detected keypoints
  
  matches_visualization.png — side-by-side correspondences visualization
  
  stitched_output.png — final stitched panorama (if homography estimation succeeds)
